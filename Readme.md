## About This Repository

This repository contains my Shell Scripting notes, examples, and practical projects.

The goal is to learn Bash scripting step by step and use it to automate common Linux and DevOps tasks.

## What You Will Learn

- Variables and data types
- User input and command-line arguments
- Operators and conditional statements
- Loops and functions
- Arrays and string operations
- File handling and error handling
- Linux command automation
- Makefile basics
- Log management and log rotation
- AWS CLI automation using Bash

## Why Shell Scripting?

Shell scripting helps automate repeated tasks, run Linux commands, manage files, check system information, and connect different tools.

It is useful for tasks such as:

- Automating backups
- Checking disk usage
- Managing logs
- Running scheduled jobs
- Automating AWS operations
- Running application build and deployment commands
