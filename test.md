## Definition

**Shell scripting** is a way to automate commands by writing them in a file and running that file using a shell such as Bash.

Instead of running the same commands manually, you can create scripts to perform tasks automatically.

This repository contains my Shell Scripting notes, examples, and projects for learning Linux automation and DevOps.

- Automate repetitive Linux tasks.
- Manage files and directories.
- Work with processes and system commands.
- Automate cloud operations using AWS CLI.
